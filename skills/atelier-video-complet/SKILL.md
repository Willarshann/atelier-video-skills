# Atelier vidéo complet

Pack de méthodes indépendant de la machine de l'auteur. Lire d'abord [references/conditions.md](references/conditions.md). Repérer le brief et les choix validés ; ne charger ensuite que les modules utiles.

| Besoin | Module à lire |
|---|---|
| Rushs/événement, récit, voix/musique, stabilisation, rendu | [montage-video-pipeline](modules/montage-video-pipeline/SKILL.md) |
| Texte parlé, français/créole, alignement ou correction de coupes | [video-sous-titres-synchronises](modules/video-sous-titres-synchronises/SKILL.md) |
| Analyser/reconstruire une référence | [video-analyse-reference](modules/video-analyse-reference/SKILL.md) |
| Changer le B-roll avec graphismes figés | [remotion-revision-medias](modules/remotion-revision-medias/SKILL.md) |
| Adapter le 9:16, plans plein écran et cadrages | [remotion-vertical-plein](modules/remotion-vertical-plein/SKILL.md) |
| Lire/transposer un pack de presets | [remotion-transposer-presets](modules/remotion-transposer-presets/SKILL.md) |

Les SKILL.md des modules servent ici de références internes ; suivre leurs liens depuis leur propre dossier. Aucun skill externe n'est nécessaire. Les scripts sont dans le module qui les documente. Lire les lignes utiles du [registre d'erreurs](references/erreurs.md) avant de produire ou corriger le défaut correspondant.

Si l'utilisateur demande un MP4 et autorise le rendu, mener le travail jusqu'au fichier vérifié et copié ; une proposition ou des stills ne remplacent pas le livrable. Ne pas laisser croire à un accès aux fichiers/apps que l'environnement n'a pas. Les dépendances de montage restent à fournir/autoriser séparément.
